# Resource-Conditioned Epistemic Access in Large Language Models

Reproducibility materials for Paper A. The benchmark contains 1,080 items across nine languages. The realised production corpus contains 143 successful Sanskrit responses representing 98 distinct benchmark items (98 Claude-family; 45 Llama-family). The human_evaluation directory contains the clean replacement independent R1/R2 evaluation of 40 realised Sanskrit responses and the separate target-language-retention adjudication record. No outcomes are imputed for unobserved language--model combinations.
